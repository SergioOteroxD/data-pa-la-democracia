# 🗳️ Data pa' la Democracia

Este proyecto de ciencia de datos tiene como objetivo analizar los ingresos y gastos reportados en las campañas políticas para alcaldías y gobernaciones en Colombia durante las **elecciones territoriales de 2023**. A través de un enfoque analítico, buscamos aportar transparencia, identificar patrones financieros y ofrecer una mirada crítica al financiamiento electoral.

## 🧾 Descripción

La financiación de campañas políticas es un aspecto crucial para la transparencia y la equidad democrática. Con base en los datos reportados por los candidatos y partidos ante el **Consejo Nacional Electoral (CNE)**, este proyecto analiza cómo se financiaron las campañas, cuánto se gastó, de dónde provienen los recursos y cómo varían estos elementos entre regiones y cargos.

## 🎯 Objetivos

- Visualizar los ingresos y gastos por candidato, partido, cargo y región.
- Identificar posibles desequilibrios o irregularidades en el financiamiento de campañas.
- Analizar la relación entre el monto invertido y el resultado electoral.
- Fomentar el acceso ciudadano a datos abiertos y facilitar su comprensión mediante visualizaciones claras e interactivas.


## 🔍 Fuentes de datos

- [Consejo Nacional Electoral (CNE) - Cuentas Claras](https://www.cne.gov.co/)
- Datos abiertos de [Función Pública](https://www.funcionpublica.gov.co/)
- Resultados electorales: [Registraduría Nacional del Estado Civil](https://registraduria.gov.co/)
- Datos geográficos de municipios y departamentos (DANE)

## 🛠️ Herramientas utilizadas

- Python (pandas, numpy, seaborn, matplotlib, plotly)
- Jupyter Notebooks
- Git & GitHub para control de versiones

## 📊 Resultados principales

- En promedio, los candidatos a gobernación reportaron más ingresos y gastos que los de alcaldía.
- Se identificaron campañas con altos ingresos en municipios con baja población.
- Algunos candidatos ganadores gastaron significativamente menos que sus contrincantes, lo que sugiere otros factores de influencia.
